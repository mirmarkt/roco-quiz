## 这是什么

通过 60 道性格题 + 15 道关系偏好题，给你**匹配一只洛克王国世界精灵**——比如「迪莫（隐藏款）」「水蓝蓝」「皇家狮鹫」「怒目怂猫」。

每个精灵都有：
- 🐾 **主卡**：精灵 + 属性 + 战斗定位 + 稀有度 + 血脉
- 📜 **精灵图鉴**：原创描述
- 💬 **群聊话术**：5 条经典语录
- 📊 **6 项种族值**：生命 / 物攻 / 魔攻 / 物防 / 魔防 / 速度（基于洛克王国世界种族值系统）
- 🩸 **血脉系统**：普通 → 混血 → 污染 → 奇异
- ⭐ **稀有度**：精灵基础 + 血脉 + 异色 / 炫彩
- 🐾 **最佳组队精灵**：互补型精灵推荐

## 设计原则

- **不直接给标签**：不出现 MBTI 字母、也不基于 MBTI 推测性向
- **6 项种族值中性化**：把 4 维 MBTI 转换成 6 项游戏种族值（生命/物攻/魔攻/物防/魔防/速度），更娱乐
- **血脉 + 稀有度**：来自洛克王国世界原作系统，强化游戏代入感
- **隐私第一**：所有数据只在浏览器

## 技术栈

- 单文件 `index.html`（HTML + CSS + JS + 75 道题 + 14 个精灵数据 + 6 项种族值 + 血脉判定 + 稀有度判定）
- 零依赖、零构建、零打包
- 深色/浅色自适应
- 移动端友好
- 部署在 **GitHub Pages**
